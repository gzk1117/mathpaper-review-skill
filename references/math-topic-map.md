# Math Topic Map

Use these categories to infer level and tag wrong questions.

## Elementary

- number sense: integers, place value, comparison, estimation
- arithmetic: addition, subtraction, multiplication, division, mixed operations
- fractions and decimals: conversion, operations, percentage
- word problems: units, rates, ratio, proportion, simple equations
- geometry: perimeter, area, volume, angles, basic shapes
- statistics: tables, bar charts, averages

## Middle School

- algebra: equations, inequalities, systems, factoring, radicals
- functions: linear, inverse proportional, quadratic basics
- geometry: parallel lines, triangles, congruence, similarity, circles, polygons
- probability/statistics: simple probability, frequency, averages, charts
- coordinate geometry: distance, midpoint, slope, line equations

## High School

- functions: quadratic, exponential, logarithmic, power, piecewise, parameter problems
- trigonometry: identities, equations, sine/cosine rules, graphs
- sequences: arithmetic/geometric sequences, recurrence, summation
- analytic geometry: lines, circles, conics, vectors, coordinate methods
- solid geometry: lines/planes, angles, distances, volume, sections
- probability/statistics: counting, distributions in school context, data analysis
- calculus intro: derivatives, monotonicity, extrema, tangent lines, area applications where included

## University

- calculus: limits, continuity, derivatives, integrals, series, multivariable calculus, vector calculus
- linear algebra: matrices, determinants, linear systems, vector spaces, linear maps, eigenvalues, diagonalization, inner products
- probability/statistics: random variables, distributions, expectation, variance, conditional probability, law of total probability, Bayes, estimation, hypothesis testing

## Cross-Level Tags

- modeling
- proof
- computation
- graph/diagram interpretation
- notation and expression
- theorem/application conditions
