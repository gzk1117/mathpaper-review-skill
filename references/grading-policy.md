# Grading Policy

## Global Principles

- Prefer the user's answer key and scoring rubric. If absent, estimate using common math grading norms.
- Award process credit for valid reasoning even when later arithmetic errors change the final answer.
- Accept equivalent forms: simplified fractions/decimals when appropriate, algebraically equivalent expressions, equivalent intervals/sets, and valid alternate proofs.
- Penalize unsupported answers in solution/proof problems when process is required.
- Mark unclear items as `needs review` instead of pretending the grade is certain.

## Objective Questions

For choice, fill-in, and short-answer items:

- Grade mainly by final answer unless work is required.
- Check equivalence, signs, units, domain/range restrictions, interval notation, exact vs approximate form, and required precision.
- If multiple answers are required, deduct for missing or extra invalid answers.

## Solution Problems

Grade by reasoning chain:

- correct setup or transformation
- valid method choice
- correct calculation/algebra
- complete final answer matching the question
- notation and domain checks when relevant

If a student makes one calculation error but continues consistently, give credit for the method and deduct for the affected result. If a wrong early step makes the rest invalid, explain the first decisive error.

## Proof Problems

Check:

- all given conditions are used correctly
- no circular reasoning
- intermediate claims are justified
- conclusion matches the task
- notation is precise enough for the level

For geometry proofs, distinguish visual assumptions from stated conditions.

## Word Problems and Modeling

Check:

- variable definitions
- equation/function/inequality model
- units and practical constraints
- reasonableness and final sentence

Deduct when the answer is mathematically correct but violates the context, such as negative length or invalid count.

## Level-Specific Focus

Elementary:

- Give extra attention to place value, operation order, units, vertical calculation, copying errors, and word-problem reading.
- Explain in concrete language and avoid overly formal terminology.

Middle school:

- Focus on equations, algebraic transformations, signs, formulas, geometric conditions, and basic function understanding.
- Call out unstable habits such as skipping steps or not checking conditions.

High school:

- Focus on function structure, parameter conditions, classification discussion, trigonometric identities, sequence logic, analytic geometry setup, vectors, and proof rigor.
- In solid geometry, separate what is known from what only appears true in the diagram.

University:

- Focus on definitions, theorem conditions, symbol discipline, quantifiers, proof completeness, and valid transformations.
- For calculus, check limit conditions, differentiability/integrability assumptions, convergence tests, bounds, substitutions, and constants.
- For linear algebra, check matrix dimensions, rank/nullity, independence, basis, eigenvalue/eigenvector definitions, and diagonalization conditions.
- For probability/statistics, check sample spaces, independence, conditional probability, distribution parameters, expectation/variance formulas, estimator assumptions, and final interpretation.
